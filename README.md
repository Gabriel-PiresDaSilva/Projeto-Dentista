# 🦷 Website Institucional — Dra. Mileny Santos

Website institucional desenvolvido para a **Dra. Mileny Santos**, cirurgiã-dentista, com o objetivo de fortalecer sua presença digital, apresentar seus serviços odontológicos e facilitar a comunicação com pacientes.

🔗 **Acesse o site:** [Dra. Mileny Santos — Odontologia](https://gabriel-piresdasilva.github.io/Projeto-Dentista/)

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica, tendo como proposta a criação de uma solução web para um cliente real.

O objetivo foi desenvolver um website institucional que transmitisse profissionalismo, confiança e acolhimento, proporcionando aos visitantes uma experiência intuitiva e facilitando o acesso às principais informações sobre o consultório.

Além do cumprimento dos requisitos acadêmicos, o desenvolvimento buscou aplicar conceitos de desenvolvimento front-end, organização de código, responsividade e experiência do usuário (UX).

## ✨ Funcionalidades

- **Página inicial:** apresentação da profissional e destaque para os principais diferenciais do atendimento.
- **Sobre:** informações institucionais e apresentação da proposta de atendimento.
- **Serviços:** apresentação dos serviços e tratamentos odontológicos.
- **Avaliações do Google:** integração com avaliações de pacientes para reforçar a credibilidade profissional.
- **Contato:** informações de atendimento, localização e canais de comunicação.
- **Integração com WhatsApp:** acesso direto para facilitar o agendamento de consultas.
- **Integração com Instagram:** acesso ao perfil profissional.
- **Design responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 🎨 Desenvolvimento

Durante o desenvolvimento, foram considerados aspectos importantes para um website institucional da área da saúde:

- Identidade visual alinhada à proposta profissional da cliente.
- Hierarquia visual para facilitar a navegação.
- Organização das informações e dos elementos da interface.
- Responsividade para dispositivos móveis e desktops.
- Facilidade de acesso aos canais de contato.
- Apresentação de avaliações para transmitir confiança aos visitantes.

## 🚀 Como executar o projeto

Para visualizar o projeto localmente:

**1. Clone o repositório**

```bash
git clone https://github.com/gabriel-piresdasilva/Projeto-Dentista.git
```

**2. Acesse a pasta**

```bash
cd Projeto-Dentista
```

**3. Execute o projeto**

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do Visual Studio Code.

## 🌐 Publicação

O website está publicado utilizando o **GitHub Pages**, permitindo acesso público sem a necessidade de configuração de um servidor próprio.

A cada atualização publicada na branch configurada para deploy, o GitHub Pages disponibiliza a versão atualizada do projeto.
